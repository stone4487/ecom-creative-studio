# 电商素材工作台 · Ecom Creative Studio

> **当前状态：产品方案与可操作原型，暂无可运行的小程序代码。**
> 这个仓库用来讲清楚「要做什么、为什么这么做、上线前有什么坑」，不是成品仓库。
> `index.html` 是一个**纯前端、单文件、可实操的工作台界面**：访客上传多类素材、配置任务、按素材位与平台生成整套版式图，逐张下载 PNG 或打包成带清单的 ZIP。图片只在浏览器本地参与 canvas 合成，不上传服务器、不调用任何 AI 接口。输出是版式演示样张，不是平台最终上架素材。产品分析、规格依据与合规说明不放在展示页里，集中在本 README 与 `docs/`。

**在线体验（可直接操作）：** https://stone4487.github.io/ecom-creative-studio/

## 一句话定位

给电商卖家的微信小程序：客户提供商品信息与各类素材图（白底图、带背景实拍、旧成品图、人物与场景参考等），一次生成按素材位与平台分好的整套素材，覆盖淘宝、京东、拼多多、抖音、小红书、亚马逊、TikTok Shop。也支持只单独生成某一个素材位。

## 原型里能真的操作的功能

页面是**纯工作台界面**（配置 → 生成 → 下载），没有产品分析板块。以下能力都能在浏览器里点着用：

### 1. 多角色素材上传与识别

- 六个素材槽位，角色互不混淆：**商品主体图**（真值源 / 必填）、多角度与细节图、人物 / 模特参考、场景 / 道具 / 光影参考、品牌资产 Logo、**旧成品素材回收**（去文字 → 抠主体 → 重排版）
- 点击或拖拽上传、支持多张、缩略图、单独删除、清空素材、内置示例图
- 上传后做**本地启发式识别**（采样边缘白像素比例 + 文件名关键词），显示识别类型与白边比例；识别错了可用下拉手动改判
- 每张图显示将执行的处理链路（主体提取 / 抠图锁主体 / 裁切原有文案区 / 只作风格参考 / Logo 注入），改判后即时更新
- 每张图单独勾选授权状态

### 2. 主题库（可自定义，数量不限）

主题是**视觉与默认文案模板**：

- 5 个内置预设（双十一、情人节、新品上市、日常上新、618 大促）
- 「+ 自定义主题」可设名称、主色 / 背景色 / 文字色、主标语、角标文案、适用场景备注，以及「主色跟随品牌主色」
- 自定义主题可编辑、删除、另存副本；保存在本机 `localStorage`，刷新后仍在；主题多时列表可滚动
- 预设主题不可直接改，但可「另存为自定义」后再改

### 3. 宣传核心要点（真正决定每张图写什么）

一次营销的内容 brief，六个字段：

| 字段 | 作用 |
|---|---|
| 核心主张 | 所有素材位的主标题，优先级高于主题标语和备用标题 |
| 主推利益点（一行一条） | 副图底部文案、详情卖点块、种草与海报的标签 |
| 促销机制 | 海报角标文案 + 详情长图底部机制条 |
| 目标人群 / 场景 | 海报辅助信息、种草话题来源 |
| 调性关键词 | 种草图的话题标签 |
| 禁用词 | 对将被写入图片的文案做合规检查，命中会在解析区、处理计划、卡片标签和 ZIP 清单里提示 |

输入下方实时显示「已解析 N 条利益点 / N 个话题标签 / 禁用词检查通过或命中」。**这是按规则排版，不是 AI 理解文案**——见「诚实边界」。

商品信息（名称、类目、卖点、品牌主色）与生成设置（7 个平台、5 个素材位、3 档输出像素、4 个处理开关）仍在侧栏，可自由组合。

### 4. 处理计划

侧栏 10 步管线实时反映当前素材与配置：素材解析 → 主题套用 → 要点应用 → 主体锁定 → 旧素材回收 → 场景融合 → 人物融合 → 品牌注入 → 合规校验（含禁用词）→ 按位导出。哪一步没素材、哪个开关关着、禁用词是否命中，都会直接显示出来。

### 5. 生成与规则校验

- 点「生成素材包」走 7 阶段进度动画；改配置也会自动刷新预览
- 结果**按素材位分组**（主图位 / 副图位 / 详情位 / 种草位 / 海报位），组内按平台出图，而不是简单按平台裁同一张图
- 每张 canvas 真的按目标比例绘制：主图位纯白底、不加一个字；场景图与海报叠主题文案与卖点
- **宣传要点写进各素材位**：主标题用核心主张、卖点块用利益点、海报角标用促销机制、种草话题来自人群与调性关键词、详情底部加机制条。改一个字段，所有相关图同步重绘
- 上传的场景参考会作为模糊背景层、人物参考作为半透明层、Logo 叠进海报与详情 —— 这些都是浏览器里真实发生的合成
- 规则引擎：跨境主图自动禁用人物、Logo、AI 标识与宣传文案，并在卡片上标出拦截原因；禁用词命中会标记风险；AI 生成标识按素材位与平台决定是否叠加；授权未确认时禁用生成
- 卡片显示目标规格、演示导出像素、要点应用数量与状态标签

### 6. 预览与导出

点击卡片放大预览（弹窗里也会列出本次主张、应用要点与促销机制）、按平台 / 素材位筛选、网格 / 列表切换、逐张下载 PNG。

**下载素材包 ZIP**：按 `素材位/平台/文件名.png` 分目录，附 `manifest.txt` 清单（任务编号、主题及标语、**本次全部宣传要点与禁用词检查结果**、平台、素材位、输出档位、授权状态、逐张目标规格与演示声明）。ZIP 由纯 JS 以 store 模式打包，没有外部依赖。

草稿与历史任务保存在本机 `localStorage`，包含主题、自定义主题库与全部宣传要点（只存配置不存图片），可一键恢复。

## 诚实边界

- 识别、抠图、去文字、场景与人物融合都是**前端近似演示**：主体提取是「去除纯白 / 近白像素」，旧成品图处理是「中心裁切掉四周文案区」，场景与人物是图层叠加。它们**不是 AI 抠图或生成式融合**，也没有接入任何模型。
- 宣传要点驱动的是**文案排版规则**：主张、利益点、促销机制、话题按固定优先级填进各素材位的文字层，不是模型对要点的语义理解，也不是自动文案生成。主图位按平台规则一律不叠文案。
- 画布是缩小版演示尺寸，卡片上同时标出「目标规格」与「演示导出像素」，两者不要混为一谈。
- 没有真实用户数据、生成结果或运营指标；没有可运行的小程序工程代码。

## 一个必须先想清楚的判断

「一次性生成一整套素材」不等于「生成一张万能图」。7 个平台的规则互相冲突：亚马逊、TikTok Shop 主图要求纯白底、商品本体、禁任何文字水印；双十一海报的核心却是促销文案。产品形态应该是**一次输入 → 分层生成 → 按素材位与平台导出**。

原型里能直观看到这个差异：白底主图不加一个字，场景图和海报叠满主题文案，跨境主图还会被规则引擎拦下人物与标识。

另外，商品保真是生死线。端到端文生图会改掉 logo、颜色、形状和配件，卖家不敢上架。正确路线是以客户上传的实拍图为真值源：抠图 + 蒙版锁死商品主体，AI 只负责背景、场景、光影和排版。

## 本地体验

直接双击 `index.html` 即可，不需要起服务、不需要联网：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

建议走一遍：上传一张自己的产品图 → 再传一张旧海报到「旧成品素材回收」和一张场景参考 → 看识别结果与处理计划 → 改判一次识别类型 → **新建一个自定义主题**（换配色与标语）→ **改宣传主张和利益点，看所有图的标题与卖点同步变化** → 故意在利益点里写一个禁用词，看风险提示 → 勾选平台与素材位 → 点「生成素材包」→ 放大预览 → 下载 ZIP 看目录结构、清单与要点留痕 → 保存草稿，再改几个字段后从历史任务一键恢复。

## 技术边界（诚实说明）

WorkBuddy 云服务提供数据库、登录、文件存储和大模型调用，**不含图像生成能力**。抠图、场景生成、超分、模板合成必须外接图像 API，这是选型和成本的大头。一套 20–40 张图是分钟级任务，小程序端必须走异步任务队列 + 进度轮询 + 订阅消息，不能同步等待。计费上建议「低清预览 → 选定再出高清」。成本量级属于估算，需要按实际 API 报价核算，本文档不给具体数字。

## 事实说明

- 页面与文档里标注「已核实」的条目都附了来源和可复核渠道，主要是政府网站、微信开放社区官方答复、平台帮助页汇总。
- 平台图片规格是**常见基准值**，规则会变，正式出图前必须到各平台卖家后台复核；二手文章错误较多（例如把《AI 标识办法》施行时间写成 2026 年 9 月，实际是 2025-09-01），不能作为规则引擎唯一依据。
- 路线图、成本判断、平台取舍、竞品判断属于**规划与推测**，不是已上线事实，也没有任何运营数据支撑。
- 赛道并非空白：美梦 AI、WeShop 唯象、鹿班、通义万相、Accio work 已覆盖「上传商品图 → 一键出套图」。差异化只能来自多平台规则引擎、商品保真与合规校验、主题模板库和素材授权留痕。
- 国内法规要求导出的 AI 图片带显式标识，但亚马逊 / TikTok Shop 主图禁止任何文字、水印、logo，两条规定直接冲突。原型里做成「按素材位分导出通道 + 主图位自动拦截标识」，**实际是否合规必须让法务和平台确认**，这里不给结论。
