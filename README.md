# 电商素材工作台 · Ecom Creative Studio

> **当前状态：产品方案与概念原型，暂无可运行的小程序代码。**
> 这个仓库用来讲清楚「要做什么、为什么这么做、上线前有什么坑」，不是成品仓库。页面里的生成结果是演示数据，不调用任何生成接口。

## 一句话定位

给电商卖家的微信小程序：上传一张商品实拍图、填清卖点和宣传主题，一次拿到按平台分好的整套素材（合规白底主图、场景主图、详情长图、种草海报），覆盖淘宝、京东、拼多多、抖音、小红书、亚马逊、TikTok Shop。也支持只单独生成某一种素材。

## 这个仓库有什么 / 没有什么

有：

- `index.html` — 可直接用浏览器打开的产品页与交互原型，GitHub Pages 可直接渲染
- `docs/PRD.md` — 产品需求文档：角色、场景、输入输出、优先级、验收标准、指标
- `docs/compliance.md` — 上线合规清单，逐条标注来源与「待确认 / 需复核」状态

没有：

- 微信小程序工程代码（尚未开工）
- 图像生成接口、抠图模型、模板合成服务
- 任何真实的用户数据、生成结果或运营指标

## 一个必须先想清楚的判断

「一次性生成一整套素材」不等于「生成一张万能图」。7 个平台的规则互相冲突：亚马逊、TikTok Shop 主图要求纯白底、商品本体、禁任何文字水印；双十一海报的核心却是促销文案。产品形态应该是**一次输入 → 分层生成 → 按平台分包导出**。

另外，商品保真是生死线。端到端文生图会改掉 logo、颜色、形状和配件，卖家不敢上架。正确路线是以客户上传的实拍图为真值源：抠图 + 蒙版锁死商品主体，AI 只负责背景、场景、光影和排版。

## 技术边界（诚实说明）

WorkBuddy 云服务提供数据库、登录、文件存储和大模型调用，**不含图像生成能力**。抠图、场景生成、超分、模板合成必须外接图像 API，这是选型和成本的大头。一套 20–40 张图是分钟级任务，小程序端必须走异步任务队列 + 进度轮询 + 订阅消息，不能同步等待。计费上建议「低清预览 → 选定再出高清」。成本量级属于估算，需要按实际 API 报价核算，本文档不给具体数字。

## 事实说明

- 页面与文档里标注「已核实」的条目都附了来源和可复核渠道，主要是政府网站、微信开放社区官方答复、平台帮助页汇总。
- 平台图片规格是**常见基准值**，规则会变，正式出图前必须到各平台卖家后台复核；二手文章错误较多（例如把《AI 标识办法》施行时间写成 2026 年 9 月，实际是 2025-09-01），不能作为规则引擎唯一依据。
- 路线图、成本判断、平台取舍、竞品判断属于**规划与推测**，不是已上线事实，也没有任何运营数据支撑。
- 赛道并非空白：美梦 AI、WeShop 唯象、鹿班、通义万相、Accio work 已覆盖「上传商品图 → 一键出套图」。差异化只能来自多平台规则引擎、商品保真与合规校验、主题模板库和素材授权留痕。
