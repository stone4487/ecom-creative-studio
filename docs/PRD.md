# 电商素材工作台 · 产品需求文档

状态：草案 v0.1 · 2026-11-09
定位说明：本文描述规划中的产品，功能均未实现。文中「验收标准」是设计目标，不是已验证结果。

## 1. 背景与问题

同一个商品铺多个平台，卖家要重复制作 20 张以上的图：白底主图、场景主图、详情长图、信息流竖图、种草笔记配图。外包设计成本高，自己修图周期长，SKU 一多就卡顿。

真正的痛点不是「不会做图」，而是三件事：

1. **规格碎**：国内主图多为 1:1，小红书要 3:4，亚马逊要 1600px 以上纯白底，抖音信息流偏竖版。
2. **规则冲突**：跨境主图禁文字水印，大促海报必须堆促销信息，一套图无法通吃。
3. **商品保真**：AI 端到端生成会改变商品形状、logo、颜色、配件，卖家不敢上架，严重时可能构成货不对板。

## 2. 目标用户与场景

| 角色 | 场景 | 关键诉求 |
|---|---|---|
| 中小卖家 / 运营 | 新品上架、大促前批量出图 | 快、便宜、能直接上传后台 |
| 跨境运营 | 同时铺亚马逊与 TikTok Shop | 白底合规、不被驳回、尺寸对 |
| 内容运营 | 小红书 / 抖音种草 | 竖版、风格统一、有文案 |

主要使用环境是手机，因此载体选微信小程序。但生成任务是分钟级的，小程序端不能同步等待。

## 3. 产品形态

**一次输入 → 分层生成 → 按平台分包导出**，而不是一键产出一张万能图。

输入：

- 产品信息：名称、类目、核心卖点、功能参数、禁用表述
- 素材图：实拍图 / 纯素材图 / 已在用的旧素材（至少 1 张，作为商品真值源）
- 宣传主题：双十一、情人节、新品上市、日常上新，或自定义
- 目标平台：7 选 N；也可只选「单独生成某个素材」

输出（按平台分文件夹的素材包）：

| 素材类型 | 用途 | 约束 |
|---|---|---|
| 合规白底主图 | 亚马逊 / TikTok Shop / 淘宝第 5 张 | 纯白 RGB 255,255,255、无文字水印、商品占比达标 |
| 场景主图 | 国内平台轮播图 | 商品本体不变，只换背景与光影 |
| 详情长图 | 详情页卖点模块 | 宽度 750px（跨境按模板） |
| 竖版海报 / 种草图 | 小红书、抖音信息流、大促 | 1080×1440 或 9:16，可叠促销文案 |

## 4. 生成链路

1. **商品保真层**：对上传图做主体分割，生成蒙版并锁死商品像素。原图的形状、logo、颜色、配件不参与任何重绘。这是整个产品的硬约束。
2. **文案与模板层**：LLM 把卖点转成主图短句、详情模块文案、种草标题；按主题选视觉模板与排版。
3. **平台规则层**：按平台校验尺寸、比例、白底 RGB、商品占比、文字占比、禁用词；规则表要可版本化、支持人工复核。
4. **合成与导出**：模板排版 → 合规校验 → AI 标识注入 → 异步打包 → 小程序端下载。

技术边界：WorkBuddy 云服务提供数据库、登录、文件存储、大模型调用，**不含图像生成**。抠图、场景生成、超分、模板合成需外接图像 API。整套任务必须走异步队列 + 进度轮询 + 订阅消息。

## 5. 功能优先级

| 优先级 | 功能 | 说明 |
|---|---|---|
| P0 | 单图上传 + 卖点表单 + 主题选择 | 最小输入闭环 |
| P0 | 主体抠图与蒙版锁定 | 商品保真的技术底座 |
| P0 | 淘宝 + 拼多多两套模板 | 规则最接近，先跑通 |
| P0 | 异步任务、进度、下载 | 分钟级任务必需 |
| P1 | 小红书种草图、节日模板库、模板复用 | 提升复用率 |
| P1 | 单素材模式（只生成海报 / 只生成主图） | 用户明确提出 |
| P2 | 亚马逊纯白底校验、TikTok Shop 适配 | 合规最复杂，单独一期 |
| P2 | 多语言输出 | 跨境需要 |
| P3 | 账号、额度计费、批量 SKU、团队空间 | 商业化 |

## 6. 非目标（P0 不做）

- 视频生成
- AI 虚拟模特 / 换脸
- 商品 3D 建模
- 平台后台一键刊登（需要各平台开放接口授权）
- 竞品图风格复刻（版权风险高）

## 7. 验收标准（设计目标，未验证）

- 商品主体一致性：输出图与输入实拍图并排比对，logo 文字、形状、颜色、配件数量不得变化；有变化即判失败并重跑
- 白底合规：背景取样 RGB 必须为 255,255,255，不能用肉眼判断
- 尺寸合规：按选定平台规则表逐张自动校验，不合规不进入导出
- 可用性：导出图可直接在对应平台后台上传，无需二次裁剪
- 任务反馈：生成期间有明确进度，失败有可读原因，不静默

## 8. 指标（规划，无历史数据）

以下均为待定义的目标，不是已观测数据：首次出图成功率、单套任务耗时、单套 API 成本、平台上传通过率、模板复用率、7 日留存。正式立项前需要先定义口径和采集方式。

## 9. 风险与待决问题

| 风险 | 状态 |
|---|---|
| AI 标识法规要求导出图带显式标识，与跨境主图禁文字水印冲突 | **待法务与平台确认，目前无确定解法** |
| 微信小程序需企业主体 + 深度合成类目 + 算法备案材料 | 需先确认主体资质 |
| 客户上传素材的商用授权、字体与模板版权 | 需在用户协议与上传流程中留痕 |
| 图像 API 成本与并发 | 需实际询价与压测，本文不估算具体数字 |
| 赛道已有美梦 AI、WeShop 唯象、鹿班等竞品 | 差异化需靠规则引擎与合规能力，不能靠「能生成」 |
